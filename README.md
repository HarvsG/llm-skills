# LLM Skills

This repository contains my custom skills to extend LLMs with features to help me prototype.

## Collection `smart-home-services`

This is a collection of skills to help you integrate with Home Assistant and directly with Ollama.

# Installation

To install the skills in Claude Code, run inside Claude Code:

```
/plugin
```

Then select "Add marketplace" and enter

```
balloob/llm-skills
```
